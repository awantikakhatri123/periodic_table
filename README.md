# ⚛️ Neon Periodic Table

An interactive periodic table of all 118 elements, built with plain HTML, CSS and JavaScript. No frameworks or dependencies.

## Features

- All 118 elements with category colors
- Search by name, symbol or atomic number
- Filter by category
- Click an element to see its details and an animated Bohr model
- Random element button
- Dark and light theme
- Responsive on desktop and mobile

## Shortcuts

- `/` focus search
- `←` `→` previous / next element
- `Esc` close popup

## Run

Download or clone the project and open `index.html` in your browser.

## Files

- `index.html` – page structure
- `styles.css` – styles and themes
- `app.js` – data and logic
